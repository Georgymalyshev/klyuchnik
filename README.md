# Ключник

**Находит ключи российских сервисов и российские персональные данные, пока они не утекли.**

Популярные сканеры секретов (gitleaks, TruffleHog, Kingfisher, Betterleaks) из российских сервисов узнают только Telegram и Яндекс. Ключи GigaChat, DaData, Т-Банка, ЮKassa, VK, Ozon, Wildberries и других сервисов они либо пропускают, либо находят как «какой-то ключ», если рядом случайно оказалось слово `key` или `token`. Российские персональные данные (СНИЛС, ИНН, паспорт) не ищет никто.

«Ключник» добавляет **30 правил**: 19 для ключей 13 сервисов, 7 для персональных данных и ещё 4 для Telegram и Яндекса (их добавляет только расширение). Для СНИЛС, ИНН, полиса ОМС и карты «Мир» он сверяет контрольные суммы, поэтому почти не путает их со случайными числами. Работает тремя способами:

| | Для кого | Что делает |
|---|---|---|
| **Сторож** | программисты | не даёт сделать коммит, если в коде ключ или СНИЛС |
| **Защитник ИИ-чатов** | все, кто пользуется GigaChat, Алисой, DeepSeek | предупреждает **до отправки** сообщения, если в нём секрет |
| **Сайт-проверялка** | все | перетащил файл и увидел, что в нём, и как отозвать найденный ключ |

Всё работает **только на вашем компьютере**: ни сторож, ни расширение, ни сайт ничего никуда не отправляют.

## Сторож для git

Нужны Python 3.10+ и git.

```
pip install git+https://github.com/Georgymalyshev/klyuchnik
cd мой-проект
klyuchnik-install
```

`klyuchnik-install` сам скачает gitleaks, если его нет (со сверкой контрольной суммы SHA-256), и поставит проверку перед каждым коммитом:

```
Ключник проверил коммит:
  НАЙДЕНО: bot.py:1  Ключ авторизации GigaChat / SaluteSpeech (Сбер)  (ZjNi***)

⛔ Коммит остановлен: в коде секрет или персональные данные.
```

- Проверить папку целиком: `klyuchnik-scan путь/к/папке`
- Убрать сторожа: `klyuchnik-install --uninstall`
- Если строка точно не секрет, допишите в конце комментарий `gitleaks:allow`.

**С pre-commit** (`.pre-commit-config.yaml`):

```yaml
repos:
  - repo: https://github.com/Georgymalyshev/klyuchnik
    rev: v0.1.0
    hooks:
      - id: klyuchnik
```

**В GitHub Actions:**

```yaml
- uses: actions/checkout@v4
- uses: Georgymalyshev/klyuchnik@v0.1.0
```

**Только правила, без Python:** файл [`klyuchnik/klyuchnik.toml`](klyuchnik/klyuchnik.toml) подключается к gitleaks или Betterleaks напрямую (`gitleaks dir . --config klyuchnik.toml`). Но тогда не будет проверки контрольных сумм, и ложных тревог станет больше.

## Защитник ИИ-чатов (расширение браузера)

Работает на GigaChat (giga.chat), Алисе (alice.yandex.ru) и DeepSeek (chat.deepseek.com). Когда вы нажимаете Enter или кнопку отправки, расширение проверяет текст. Если в нём секрет, оно останавливает отправку и предлагает выбор: **скрыть** секреты, **вернуться** к тексту или **всё равно отправить**.

**Установка в Chrome или Яндекс Браузер:** скачайте репозиторий (Code → Download ZIP), откройте `chrome://extensions`, включите «Режим разработчика», нажмите «Загрузить распакованное расширение» и выберите папку `extension`. Попробовать расширение без настоящих чатов можно на тестовой странице: значок расширения → «Открыть тестовую страницу».

**Firefox:** `about:debugging` → «Этот Firefox» → «Загрузить временное дополнение» → файл `extension/manifest.json`.

Расширение хранит только счётчики (сколько было предупреждений и что выбрал человек). Сами сообщения и секреты оно не сохраняет.

## Сайт-проверялка

Папка [`site`](site): откройте `site/index.html` в браузере или опубликуйте папку на GitHub Pages. Файл читается прямо в браузере и никуда не загружается.

## Как устроено

```
klyuchnik/klyuchnik.toml   правила (регулярные выражения) — единый словарь
        │
        ├── gitleaks + klyuchnik/checks.py  → сторож и klyuchnik-scan (Python)
        └── tools/build_extension.py → extension/rules.js → расширение и сайт (JavaScript)
```

1. **Правило** (регулярное выражение) находит всё, что *похоже* на ключ или документ.
2. **Проверка** отбрасывает случайные совпадения: контрольные суммы СНИЛС, ИНН, полиса ОМС и карты «Мир», расшифровка ключа GigaChat (это Base64 от двух UUID), поля внутри токена Wildberries, «случайность» ключей с приставкой.
3. Один и тот же словарь работает в Python (сторож) и в JavaScript (расширение и сайт). Тест проверяет, что обе версии отвечают одинаково.

## Правила

**Состояние:** «документация» — формат взят из официальной документации или SDK. «Нужен тестовый ключ» — формат в документации не описан, правило составлено по косвенным признакам.

| Правило | Что ищет | Как узнаёт | Состояние |
|---|---|---|---|
| klyuchnik-gigachat-auth-key | ключ авторизации GigaChat / SaluteSpeech | строение: Base64 от «UUID:UUID» | документация + проверка |
| klyuchnik-tinvest-token | токен T-Invest API | приставка `t.` | документация, длину уточнить |
| klyuchnik-tbank-terminal-password | пароль терминала Т-Кассы | имя переменной | нужен тестовый ключ |
| klyuchnik-yookassa-secret-key | секретный ключ ЮKassa | приставка `live_` / `test_` | длину уточнить |
| klyuchnik-vk-token | ключ доступа VK | приставка `vk1.a.` | длину уточнить |
| klyuchnik-vk-token-old | ключ доступа VK, старый вид | 85 hex-символов рядом с `vk` | нужен тестовый ключ |
| klyuchnik-dadata-key | ключ и секрет DaData | 40 hex-символов в тексте, где есть «dadata» | секрет уточнить |
| klyuchnik-ozon-seller-key | Api-Key Ozon Seller | UUID после `Api-Key` в тексте про Ozon | нужен тестовый ключ |
| klyuchnik-ozon-performance-secret | client_secret Ozon Performance | рядом `…@advertising.performance.ozon.ru` | нужен тестовый ключ |
| klyuchnik-wb-token | токен Wildberries | JWT с полями `sid`, `acc`, `s` | документация + проверка |
| klyuchnik-avito-secret | client_secret Avito | имя переменной в тексте про Avito | нужен тестовый ключ |
| klyuchnik-2gis-key | ключ API 2ГИС | UUID v4 после `key` в тексте про 2ГИС | документация (примеры) |
| klyuchnik-selectel-token | API-ключ Selectel | вид `…_номер-аккаунта` после `SEL_TOKEN` / `X-Token` | нужен тестовый ключ |
| klyuchnik-selectel-password | пароль сервисного пользователя Selectel | `OS_PASSWORD` в тексте с `selcloud` | документация |
| klyuchnik-timeweb-token | токен Timeweb Cloud | JWT после `TWC_TOKEN` и подобных | документация, поля JWT уточнить |
| klyuchnik-cloudru-secret | секрет ключа Cloud.ru | имя переменной | нужен тестовый ключ |
| klyuchnik-kontur-focus-key | ключ Контур.Фокус | 40 hex после `key` в тексте про Контур | документация |
| klyuchnik-kontur-diadoc-key | ключ разработчика Диадок | `ddauth_api_client_id=` | документация |
| klyuchnik-kontur-extern-key | ключ Контур.Экстерн | GUID после `X-Kontur-Apikey` | документация |
| klyuchnik-snils | СНИЛС `XXX-XXX-XXX XX` | вид + контрольное число | документация (ПФР) |
| klyuchnik-snils-bare | СНИЛС из 11 цифр подряд | слово «СНИЛС» рядом + контрольное число | документация (ПФР) |
| klyuchnik-inn | ИНН физического лица (12 цифр) | слово «ИНН» рядом + две контрольные цифры | алгоритм ФНС |
| klyuchnik-passport | паспорт РФ | слово «паспорт» / «серия» рядом + год бланка | ПП РФ № 2267 |
| klyuchnik-mir-card | карта «Мир» | начало 2200–2204 + алгоритм Луна | ISO/IEC 7812 |
| klyuchnik-oms | полис ОМС (16 цифр) | слово «полис» / «ОМС» рядом + алгоритм Луна | приказ ФОМС № 79 |
| klyuchnik-phone | мобильный телефон | `+7 9XX…` / `8 9XX…` | только предупреждение |

ИНН организации (10 цифр) правила **не ищут**: это открытые данные из ЕГРЮЛ.

## Проверка

```
python -m unittest          # 40 тестов: проверки, правила, сторож, расширение, сайт
python tools/build_extension.py   # после изменения правил: пересобрать расширение и сайт
```

Тесты используют только выдуманные ключи и номера. Программа создаёт их во время запуска, в коде их нет. Тесты расширения запускаются в браузере Edge или Chrome без окна.

## Важно

- «Ключник» никогда не проверяет, работает ли найденный ключ, и никуда его не отправляет.
- Школьный проект, сделанный с помощью ИИ-ассистента Claude Code. Что делал ИИ, а что автор, записывается в журнал использования ИИ, а коммиты, где код писал ИИ, помечены строкой `Co-Authored-By`.
